# modules/enzyme_eng — 효소 공학·공정 최적화 (스펙)

로드맵 3단계. **수익 모델의 중심**이다.

## 포지셔닝
Cradle과 Arzeda는 효소를 설계하지만 다운스트림 정제 공정까지 함께 제공하는
회사는 드물다. 효소를 잘 설계해도 정제가 안 되면 공정이 성립하지 않는다.
AEX 크로마토그래피, HCP 저감, 시알릴락토스 효소 합성 경험이 차별점이다.

## core 재사용
- `core.structure` 야생형 효소 구조 확보와 활성부위 정의 — 그대로 사용
- `core.validation` 설계 변이체가 실제 활성 데이터와 맞는지 — 지표만 교체
  (EF 대신 Spearman ρ, 예측 ΔΔG vs 실측 활성)
- `core.report` 그대로 사용

## 구현 범위
1. 변이체 설계 — ProteinMPNN / ESM 기반 안정성·활성 변이 제안
2. 활성부위 모델링 — 기질 도킹으로 변이 효과 예측
3. 발현·정제 예측 — pI, 응집 경향, 소수성 패치로 AEX 조건 제안
4. 공정 조건 — 버퍼, pH, 전도도 스크리닝 설계

## 검증 게이트
공개된 효소 변이체 데이터셋(예: 알려진 활성 변이 세트)에서 Spearman ρ ≥ 0.4를
요구한다. 미달이면 설계 제안을 고객에게 내지 않는다.
