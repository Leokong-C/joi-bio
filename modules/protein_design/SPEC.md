# modules/protein_design — 항체·바인더 설계 (스펙)

로드맵 4단계. 최종 목표이되 순서는 마지막이다.

## 왜 마지막인가
갤럭스는 서울대 연구실 20년 축적 위에 420억원과 6년을 더해 de novo 항체
설계에 도달했고 AstraZeneca와 공동연구 중이다. 1인 체제로 정면 추격은 불가능하다.
모듈 1·3으로 구조 처리와 검증 프레임워크가 완성된 뒤 그 위에 얹는다.

## 저분자와 기술 스택이 겹치지 않는 점
저분자는 포켓에 작은 분자를 끼우는 문제(도킹, FEP)이고, 항체는 넓고 평평한
계면을 설계하는 문제(CDR 루프, RFdiffusion, ProteinMPNN)다. 입력도 도구도
검증 방법도 다르다. 동시에 시작하면 둘 다 미완성으로 끝난다.

## core 재사용
- `core.structure` 에피토프 정의로 확장 (포켓 → 계면)
- `core.validation` 지표 교체 (EF → 예측 결합 계면의 실측 재현율)
- `core.report` 그대로 사용

## 구현 범위
1. 에피토프 선정 — 표면 노출, 보존도, 기존 항체 회피
2. 바인더 생성 — RFdiffusion / ProteinMPNN
3. 복합체 평가 — co-folding 모델로 계면 품질 예측
4. 발현 가능성 필터 — 응집, 면역원성, 생산성

## 전제
GPU가 필요하다. GitHub Actions 무료 러너로는 불가능하므로 Modal 또는 RunPod을
붙이고 Actions는 오케스트레이션만 담당한다.
