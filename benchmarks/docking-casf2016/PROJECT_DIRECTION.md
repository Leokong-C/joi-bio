# CASF-2016 스코어링 벤치마크 — 프로젝트 방향성

작성 2026-10-24 · 이 문서의 모든 수치는 저장된 아티팩트에서 다시 읽어 확인한 값입니다.

## 0. 이 프로젝트가 묻는 것

**스코어링 함수가 결합 친화도와 상관을 보인다는 사실은, 그 함수가 결합을 모형화한다는 증거가 되는가?**

CASF-2016 코어셋 285개 복합체(57개 타깃 × 5개 리간드, 실험 logKa 2.07–11.82)에서
AutoDock Vina 1.2.7을 세 축(도킹 능력·스코어링 능력·순위 능력)으로 해부하고,
**사소한 기술자로 만든 영가설 모델**과 대조하는 것이 설계의 핵심입니다.

## 1. 지금까지 확립된 것

### 1.1 영가설이 물리 기반 스코어링을 거의 삼킨다

| 예측자 | Pearson R | 잔차 SD | 타깃 내 ρ |
|---|---|---|---|
| RF-Score v2 (ML, PDBbind 학습) | **0.741** | 1.46 | 0.561 |
| RF-Score v1 | 0.713 | 1.53 | 0.514 |
| LLM zero-shot (+PDB ID) | 0.689 | — | 0.554 |
| 사소한 영가설: 랜덤 포레스트 | 0.547 | 1.82 | 0.512 |
| **Vina (결정 포즈)** | **0.502** | 1.88 | 0.437 |
| 사소한 영가설: 리간드 중원자 수 단독 | 0.482 | 1.91 | **0.582** |
| Vinardo | 0.428 | 1.97 | 0.411 |

영가설을 통제한 뒤 남는 고유 기여(ΔR²): **Vina 0.041**, Vinardo 0.027, RF-Score v2 **0.251**
(편상관 +0.598, p = 4.6e-29). 타깃 내 순위에서는 **리간드 중원자 수 단독(ρ 0.582)이 전부를 이깁니다.**

![스코어링 지형]({{artifact:f8d04705-4a22-4000-bc69-651a4fbbe5fc}})

### 1.2 실패는 Vina의 경험식 탓이 아니다

MM/GBSA(285개 중 무작위 47개, 성공률 87 %, 복합체당 252초)는 R = 0.385로 같은 부분집합의
Vina(0.368)보다 높지만 영가설(0.549)에 크게 못 미칩니다. 영가설을 제거한 뒤 고유 기여는
**ΔR² = 0.001 (p = 0.80)** — Vina 0.003(p 0.69), Vinardo 0.001(p 0.80)과 구별되지 않습니다.
같은 조건에서 RF-Score v2만 0.271(p = 3e-6)을 남깁니다. 비용은 MM/GBSA 252초 : Vina 도킹 94초 :
RF-Score 1.3초.

### 1.3 탐색은 되는데 선택이 안 된다

top-1 ≤2 Å **66.3 %**, 반환된 최선 모드 ≤2 Å **86.7 %**, top-1 중앙값 0.935 Å.
PoseBusters 물리 타당성 95.8 %, 타당하면서 ≤2 Å 64.4 %(n = 284).
탐색량을 4배(exhaustiveness 32, 34.8 CPU-시간)로 올려도 66.5 %에 그치고, 시드만 바꿔도
284건 중 **27건이 2 Å 합격/불합격을 뒤집습니다**(시드 SD 0.41 pt).

### 1.4 친화도를 가장 잘 맞히는 모델이 포즈는 가장 못 고른다

Vina의 9개 포즈를 RF-Score v2로 재순위하면 선택이 **나빠집니다**:
≤2 Å 66.0 % → **40.1 %**(천장 86.5 %), ≤1 Å 51.8 % → 29.8 %, 중앙값 0.97 → 2.68 Å.
15건 구제·88건 파괴(순 −73). ML의 우위는 친화도 순위에서 포즈 순위로 **이전되지 않습니다.**

![포즈 재순위]({{artifact:5e3aaacd-1e8b-4d4b-92e6-75d2b203979f}})

### 1.5 LLM의 자기보고 신뢰도는 자기 오답을 정렬하지 못한다

855건의 구조화 예측(조건 A 리간드만 / B +단백질명 / C +PDB ID):

| 조건 | 정확도 | AURC | 신뢰도 무작위 셔플 AURC | 80 % 커버리지 선택 정확도 |
|---|---|---|---|---|
| A: 리간드만 | 0.495 | 0.459 | 0.508 | 0.499 |
| B: +단백질명 | 0.744 | 0.249 | 0.256 | 0.758 |
| C: +PDB ID | 0.761 | 0.236 | 0.244 | 0.761 |

셔플 대조와의 차이가 순열 SD(0.012) 수준입니다. 80 % 커버리지 선택 정확도가 전체 정확도와
같아 **기권으로 얻는 것이 없습니다.** 오염 검사는 음성이었습니다 — "안다"고 주장한 복합체가
오히려 더 못 맞혔습니다(R 0.641, n = 126 vs 0.730, n = 159).

## 2. 아직 공백인 것

1. **라벨 자체의 잡음을 모른다.** 모든 R 값의 천장이 PDBbind logKa의 재현성에 묶여 있는데
   그 값을 추정한 적이 없습니다.
2. **스크리닝 능력 축이 없다.** CASF의 네 축 중 하나가 통째로 빠져 있습니다.
3. **데이터셋 일반화가 없다.** CASF-2016 단일 셋입니다.
4. **공동접힘(co-folding) 비교자가 없다.** Boltz-2 등은 GPU가 필요합니다.
5. **강체 수용체 가정을 깬 적이 없다.** 벤치마크한 모든 방법이 이 가정을 공유합니다.
6. **난이도 축이 라벨 유병률을 재고 있었다.** 이진 정확도가 리간드 크기에 따라
   0.709 → 0.758 → 0.828로 오르지만, 라벨 자체가 크기와 상관(R +0.482)되어 있어
   난이도가 아니라 유병률을 측정한 것입니다. 독립 좌표가 필요합니다.

## 3. 오늘 열린 새 역량 — ToolUniverse

`tooluniverse` 1.5.7 설치, 도구 **2,719개** 등록, 워크플로 스킬 `tooluniverse-research`
(156개) 발행 완료. 도구 명세가 참조하는 256개 호스트 중 **25개가 샌드박스에서 도달 가능**하며,
오늘 `www.bindingdb.org`와 `pharos-api.ncats.io` 두 곳의 접근 승인을 받아 **위 공백 중
1·2·6번에 직접 쓸 수 있는 경로가 열렸습니다.**

검증된 호출: PubChem(metformin → CID 4091), UniProt(P00519), ChEMBL(CHEMBL941 → imatinib),
EuropePMC 문헌 검색, **Pharos(ABL1 → TDL `Tclin`, novelty 0.00024)**,
**BindingDB(P00519 → 1 MB 친화도 레코드)**.

## 4. 방향성 — 세 트랙

### A. 논문 트랙

현재 판단은 그대로입니다: **워크숍 포스터·프리프린트는 가능, 저널은 아직**.
저널로 가려면 §2의 2·3·4번이 메워져야 합니다. 다만 §1.2(MM/GBSA)와 §1.4(포즈 재순위)가
더해지면서 논지가 "Vina가 약하다"에서 **"친화도 상관은 결합 모형화의 증거가 아니다"**라는
방법론 주장으로 올라섰고, 이 주장은 단일 데이터셋으로도 성립합니다.

### B. abstain-dti 기여 트랙

`Pseudo-Lab/abstain-dti`는 읽기 전용으로 두고 모든 편집은 노션에서만 합니다.
우리 결과가 그 저장소의 미해결 항목 세 곳에 직접 대응합니다:
§1.2 "결함의 직접 증거가 아직 없음" ← §1.5의 셔플 대조,
§5.5 축 검증 ← §2.6의 유병률 혼입 발견,
§4.3 신뢰도 동점 처리 ← 855건 분포.

### C. 공개 트랙 (LinkedIn)

지형 그림 두 장(`casf2016_scoring_comparison.png`, `casf2016_llm_axis.png`)을 앞에 두고
세로 포스터를 마지막에 배치하는 구성을 유지합니다. 전체 데이터 공개가 아니라 명확한 그림과
결과 중심입니다.

## 5. 실행 순서

| 순서 | 작업 | GPU | 새로 필요한 것 | 상태 |
|---|---|---|---|---|
| 1 | **라벨 잡음 상한 (E3)** — BindingDB·ChEMBL에서 같은 쌍의 Ki/Kd/IC50을 모아 PDBbind logKa와 대조, 측정 간 산포로 R의 천장을 추정 | 불필요 | BindingDB ✔ | **다음** |
| 2 | 모든 예측자의 AURC (아이디어 2) — Vina 점수 크기, RF-Score **트리 간 분산**, MM/GBSA 수렴도, 영가설 포레스트 분산을 LLM 자기보고와 같은 잣대로 | 불필요 | 없음 | 대기 |
| 3 | **문헌량 공변량 (E1)** — EuropePMC·iCite로 57개 타깃의 문헌량을 세고, LLM의 +단백질명 이득(0.384 → 0.655)이 문헌량을 따라가는지 | 불필요 | EuropePMC ✔ | 대기 |

## 6. 장비 의존 항목

`microsoft/bioemu2` README는 "requires Linux and an NVIDIA GPU; macOS and Windows are not
supported"로 명시하고 compute capability ≥ 7.0, 문맥 병렬 샘플링에는 GPU 4장 이상을 요구합니다.
bioemu2는 스코어링 함수가 아니라 구조·동역학 생성기이며, 그 가치는 **지금까지 벤치마크한
모든 방법이 공유하는 강체 수용체 가정을 깨는 유일한 경로**라는 점에 있습니다.
GPU Linux 장비 한 대가 `boltz`·`diffdock`·`esmfold2` 스킬도 함께 엽니다.

## 7. 열린 결정 사항

1. 1번(라벨 잡음)과 2번(AURC) 중 어느 쪽을 먼저 둘지 — 1번이 해석을 가장 크게 바꾸고,
   2번이 abstain-dti 기여에 가장 직접적입니다.
2. 논문 트랙을 프리프린트로 먼저 낼지, 스크리닝 축(6번)까지 채우고 저널을 노릴지.
3. GPU 장비 조달 여부와 시점.

- PR #1이 병합되면 PR #3이 `main`으로 재기준됩니다.
