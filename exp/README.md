# `exp/` — 검증을 통과하지 못한 중간 산출물

**이 폴더의 화합물 목록은 후보 추천이 아닙니다.** 저장소가 공개로 전환된
2026-11 시점에 이 경고를 답니다.

## 무엇이 들어 있나

| 파일 | 내용 |
| --- | --- |
| `*/treatment/candidates_top20.jsonl` | 도킹 점수 상위 20개 (타깃별) |
| `*/treatment/docked_all.jsonl` | 전체 순위 약 2,157개 |
| `*/control/docked_all.jsonl` | 대조군 수용체로 같은 라이브러리를 도킹한 것 |
| `EPAS1/audit/library_pubchem.jsonl` | PubChem 물성 매칭으로 다시 만든 라이브러리 |
| `*/pymol/*.sdf`, `*/flex/poses/*.pdbqt` | 결합 포즈 좌표 |

전부 **공개 ChEMBL 화합물**입니다. 신규 구조도, 합성한 물질도 없습니다.

## 왜 후보로 읽으면 안 되나

우리 자신의 감사에서 나온 것들입니다. 숨기지 않고 적습니다.

**1. 기억이 도킹을 이긴다.** 각 화합물을 "자기 자신을 뺀 활성과의 최대 ECFP4
Tanimoto" 로만 순위 매기면 AUC 0.9637 이 나옵니다. AutoDock Vina 는 0.7717
입니다. 단백질도 구조도 학습도 쓰지 않은 순위가 도킹을 이깁니다. 원인은
decoy 선택 규칙의 Tanimoto 상한 0.35 가 만든 간격이고, 라이브러리를 바꿔도
사라지지 않았습니다. **이 벤치마크로는 도킹이 작동한다는 것을 증명할 수
없습니다.** → `scripts/leakage_audit.py`

**2. 후보와 음성을 같은 집합에서 뽑았다.** `candidates_top20.jsonl` 의
화합물은 같은 실행에서 `label: "decoy"` 로 라벨된 것들입니다. 파이프라인이
음성으로 센 것을 후보로 내놓고 있었습니다. 이후 평가셋과 스크리닝셋을
분리했지만 이 파일들은 그 전 산출물입니다.

**3. 간판 숫자가 아직 예비치다.** "상위권 enrichment 의 75% 가 구조 선택
편향에서 온다" 는 재측정이 두 번 실패했습니다 — 2026-10 은 라이브러리 결함
(불소 원자만 세도 게이트 PASS 3/3), 2026-11-01 은 timeout 으로 16개 샤드 중
7개 취소. 양 팔 모두 평가셋이 불완전합니다.

**4. 실험 확인이 하나도 없습니다.** 습식 검증을 한 적이 없습니다. 여기 있는
어떤 화합물도 어떤 타깃에 결합한다고 측정된 바 없습니다.

## 그럼 이 저장소의 산출물은 무엇인가

**"가상 스크리닝 숫자 중 얼마가 인공물인가" 를 재는 도구들**입니다.

| | |
| --- | --- |
| `core/validation/gate.py` | 검증 게이트. 대조군 없이는 PASS 를 주지 않고 ABSTAIN 을 냅니다 |
| `scripts/leakage_audit.py` | 기억 베이스라인 — 벤치마크가 외우기로 풀리는지 |
| `scripts/trivial_baselines.py` | 단일 기술자 — 원자 하나 세는 것으로 풀리는지 |
| `core/validation/perturb.py` | 도구 출력 교란 감사 |

이쪽이 남이 자기 스크리닝에 돌려볼 값이 있는 부분입니다.
