# ⚠️ 후보 추천이 아닙니다

이 폴더의 화합물 목록은 **검증을 통과하지 못한 중간 산출물**입니다.

- 학습도 단백질도 구조도 쓰지 않는 **기억 베이스라인(AUC 0.9637)이
  도킹(0.7717)을 이깁니다.** 이 벤치마크로는 도킹이 작동한다는 것을
  증명할 수 없습니다
- **실험 확인이 하나도 없습니다.** 어떤 화합물도 어떤 타깃에 결합한다고
  측정된 바 없습니다
- 전부 공개 ChEMBL 화합물이고 신규 구조가 아닙니다
