# 타깃 선정 기준 — 새 파이프라인

CEO 지시 (2026-11-11): 운영 라인은 별도 창으로, FLOOR 는 병행, **이 라인은
타깃을 갈아끼운 새 파이프라인의 후보를 도출한다.**

기준을 **측정 전에** 적는다. 결과를 보고 문턱을 옮기면 선정이 아니라 합리화다.

---

## 0. 왜 타깃을 바꾸는가

EPAS1 은 후보가 나쁜 것이 아니라 **벤치마크로 실격**했다. 2026-11-07 에
원인을 확정했다 — decoy 생성 규칙이 아니라 **활성군 자체**다.

| | EPAS1 고정본 실측 (2,160개 / 활성 60) |
| --- | --- |
| 활성 상호 유사도 중위 (NN Tanimoto) | **0.7945** |
| 0.6 이상 유사체를 가진 활성 비율 | **86.7%** |
| 0.8 이상 | 46.7% |
| 활성 Murcko 골격 수 | 22종 |
| 기억 베이스라인 nEF1% / AUC / BEDROC | **1.000 / 0.9637 / 0.9549** |
| 게이트 | **PASS 3/3** |

골격이 22종인데도 실격이라는 점이 중요하다. **"한 시리즈"는 골격 수가
아니라 유사도 수준의 문제다.** 골격만 세면 통과시켰을 것이다.

단백질도 구조도 도킹도 없이 "활성끼리 닮았다"만 세는 방법이 게이트를
3/3 으로 통과하는 벤치마크에서는 **도킹이 작동하는지 물을 수 없다.**

## 1. 합격 조건

네 가지를 모두 만족해야 후보다. 하나라도 어긋나면 음성 결과로 기록하고
넘어간다.

| | 조건 | 문턱 | EPAS1 |
| --- | --- | --- | --- |
| **C1** | 기억 베이스라인이 게이트를 통과하지 **못할 것** | 3개 지표 중 2개 미만 | PASS 3/3 → 실격 |
| **C2** | 활성군이 한 덩어리가 아닐 것 | 중위 NN < 0.45, 0.6 이상 비율 < 0.40 | 0.795 / 0.867 → 실격 |
| **C3** | 비활성이 **실측**일 것 | 추정 decoy 금지 | 측정 비활성 0개 → 실격 |
| **C4** | 도킹 가능한 구조가 **2개 이상** | 치료군·대조군 양팔용 홀로 구조 | (해당 없음) |

### 문턱을 이렇게 잡은 근거

**C1 이 본 조건이고 C2 는 그 원인을 보는 창이다.** C1 만으로 거를 수
있지만, C2 가 없으면 왜 통과했는지 설명하지 못한다.

중위 NN 0.45 는 EPAS1(0.795)과 M1 무스카린(0.264, 10-29 실측) 사이에
둔 값이다. 양쪽 실측 사이의 중간이지 문헌 값이 아니다 — **임의 선택임을
명시한다.** 측정이 쌓이면 다시 잡는다.

**C3 이 타깃 풀을 정한다.** 추정 decoy 를 쓰면 Tanimoto 상한이 다시
들어와 지금 재려는 바로 그것을 가린다. 그래서 1차 풀은 TDC Butkiewicz
HTS 셋이다 — 비활성이 추정이 아니라 실제로 시험해 음성으로 나온 화합물이다.

**C4 는 마지막에 본다.** 구조가 있어도 C1~C3 가 깨지면 쓸모가 없고,
구조 확인은 비싸다. 순서를 바꾸면 헛돈다.

## 2. 재는 방법

`scripts/screen_targets.py`. 타깃마다 두 가지를 낸다.

- **활성 전수의 응집도** — 타깃의 성질은 전수에서 나온다
- **EPAS1 과 맞춘 부분표본** (2,157 / 활성 60) 의 기억 베이스라인 —
  n 과 활성 비율이 같아야 EF 천장이 같고, 그래야 숫자를 나란히 놓는다

지문은 SieveStack 과 동일한 Morgan radius=2, fpSize=4096 을 쓴다. 다르면
외부 숫자와 비교가 안 된다.

**잣대 검증 완료.** 이 스크립트를 EPAS1 고정본에 돌려 위 표의 수치가
그대로 재현되는 것을 확인했다(nEF1% 1.000, AUC 0.9637, 중위 NN 0.7945).
새 타깃 수치는 EPAS1 과 같은 자로 잰 값이다.

## 3. 이 선정이 바꾸지 않는 것

- 게이트가 PASS 하지 않으면 후보 화합물을 보고서에 올리지 않는다
- 대외 보고는 치료군과 대조군을 함께, 대조군을 편향 없는 하한으로
- 기억 베이스라인을 같은 표에 나란히 싣는다
- 음성 결과도 결과다 — 떨어진 타깃과 이유를 함께 적는다

타깃을 바꾸는 것은 **벤치마크를 고치는 일**이지, 보고 규율을 느슨하게
하는 일이 아니다.

### 함께 나온 것 — 게이트 EF1% 문턱이 헐겁다

기억 베이스라인만으로 45회 측정(9타깃 × 5씨앗) 중 **EF1% ≥ 5.0 을 41회
(91%) 돌파**한다. AUC 44%, BEDROC 51% 와 대비된다.

활성 60개 / 2,157개에서 EF1% 천장은 약 35.95 이므로 문턱 5.0 은 **천장의
14%** 다. 단백질도 구조도 없이 활성끼리의 닮음만 세는 방법이 거의 항상
넘는 문턱은 변별하지 못한다.

→ 제안: 게이트의 `ef1` 절대 문턱을 **nEF1% 기준으로 바꾼다.**
이 변경은 운영 라인 게이트에도 함께 적용돼야 하므로 CEO 결정이 필요하다.

### 결정 — nEF1% 0.40, 치료군에만 적용 (2026-11-16, CEO)

`THRESHOLDS = {"nef1": 0.40, "auc": 0.70, "bedroc": 0.30}`.

**0.40 의 근거.** 선정 타깃 오렉신1 의 기억 베이스라인은 5씨앗 전부 0.364
이하이고, 실제 도킹 치료군은 0.773(MET)~0.909(EPAS1) 다. 그 사이에 둔 값이다.

| --- | --- | --- |
| 기억 베이스라인 45회 (9타깃×5씨앗) | 중위 0.409 · 범위 0.091~0.864 | `43040414978` |
| └ 오렉신1 5씨앗 | 중위 0.273 · **최대 0.364** | 같은 run |

| 도킹 치료군 MET | 0.773 | `39186378315` |
| 도킹 대조군 EPAS1 (유사도 0.07 구조) | **0.227** | `39100482267` |

**대조군에는 적용하지 않는다.** 대조군은 편향 없는 하한이라 enrichment 가
낮은 것이 설계대로다. 같은 잣대로 재면 거의 항상 미달해 규칙 2 의 양팔
보고가 막힌다. `--arm control` 로 부르면 판정은 `CONTROL_REFERENCE` 가 나오고
지표는 그대로 산출된다 — 면제는 판정뿐이다.

**교체가 실제로 변별력을 회복시킨다는 증거.** 구 문턱에서 EPAS1 대조군은
EF1% 8.17 / AUC 0.716 / BEDROC 0.300 으로 **절대 문턱 3개를 전부 통과**했다.
벤치마크와 유사도 0.07 인 구조가 그랬다. nEF1% 0.40 에서는 0.227 로 미달한다.

**운영 라인 재판정 — 원본 `docked_all.jsonl` 로 실제 재계산.** 치료군은
EPAS1 0.909, MET 0.773 으로 신 문턱도 3/3 통과해 **판정이 뒤집히지 않는다.**
대조군만 `ABSTAIN → CONTROL_REFERENCE` 로 바뀐다.

**한계 — 숨기지 않는다.** 9타깃을 모두 모으면 0.40 에서도 기억이 53% 통과하고,
기억 최고치(0.864, 콜린수송체)는 도킹 치료군보다 **높다.** 단일 문턱으로 기억을
전부 떨어뜨리면서 도킹을 통과시키는 자리는 없다. 이 문턱은 선정 타깃에서
작동하는 것이고, 기억 베이스라인은 계속 같은 표에 싣는다.

**함께 되살린 안전장치.** 활성 비율 과다 검사가 `ef1_unreachable`(EF1% 천장이
절대 문턱 아래로 내려갔는가) 에 간접 구현돼 있었다. nEF1% 는 그 천장으로
나누므로 조건이 영구히 거짓이 되어 검사가 조용히 죽는다. 같은 지점을
`ACTIVE_FRACTION_MAX = 0.20` 으로 직접 적었다 — 구 조건은 천장 ≈ 1/활성비율
이므로 활성 비율 20% 초과와 같았다. `scripts/gate_selfcheck.py` 가 매번 검증한다.

### 음성 결과

구조 탐침이 두 번 조용히 틀린 수를 냈다. 1차는 나트륨 이온을 리간드로

'ELECTRON' 으로만 찾아 전부 0 이 됐다)를 함께 고쳐 4차를 돌렸다.

| 항목 | 3차 대비 |

표시가 뜨면 이번처럼 원인을 끝까지 본다.

**양팔 비교가 불가능하다.** 구조가 하나뿐이고 그마저 리간드가 없다.

### 결론

**PH20 은 도킹 벤치마크 타깃으로 쓸 수 없다.** C3·C4 둘 다, 넉넉히 봐도
경로가 없다. 활성군 응집도(C1·C2)는 잴 재료 자체가 없어 측정하지 못했다.

이건 PH20 이 가치 없다는 뜻이 아니라 **이 파이프라인의 질문과 맞지 않는다**는
뜻이다. PH20 의 실제 쓰임은 저분자 억제 표적이 아니라 피하투여 보조 효소
(rHuPH20)이고, 공개된 작업 대부분이 단백질 변이체 특허다.

### 탐침 결함 3차 — 당사슬이 리간드로 세어지고 있었다

PH20 을 재다가 잡았다. 당사슬(NAG)·지질(3PE·PGW)·계면활성제(SOG·BOG)는
분자량 150 을 넘어 하한을 통과한다. 이름 목록으로 걸러내도록 고쳤다.

**자체 점검에 음성 항목을 넣었다.** 지금까지 점검은 "있어야 할 리간드가 0 으로
나오는" 한 방향만 봤고, 반대 방향(리간드가 아닌 것을 리간드로 세는 것)은 못
잡았다. 그래서 세 번 중 두 번을 눈으로 발견했다. 이제 9JUB 가 **0 이 나와야
통과**하는 항목으로 들어가 있다.

### 이 수정이 바꾼 이전 수치 — 하나

| 타깃 | 이전 | 수정 |
| --- | --- | --- |
| **CACNA1G (Cav3)** | 홀로 2 → C4 통과 | 홀로 **1** → C4 **실패** (6KZO 는 NAG·3PE 뿐) |

다른 타깃은 전부 동일하다. Cav3 는 이미 C1 에서 불안정이었으므로
**1순위 권고(오렉신1)는 바뀌지 않는다.** 실행 `43850320405`, 자체 점검 4/4.

### 1차 빌드가 감사를 통과하지 못했다
