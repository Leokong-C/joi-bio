## 2. A안 재실행 — 75%를 예비치에서 결과로

## 3. 교란 5 (기억) — 원인 진단이 틀렸다 (2026-11-07 정정)

**10-29 에 내린 진단: "원인은 decoys.select 의 Tanimoto 상한 0.35 가 만든
간격이다." 틀렸다.** 상한은 기여 요인이고, 지배 변수는 따로 있다.

같은 타깃·같은 풀에서 상한만 바꿔 측정했다.

| | nEF1% | AUC | 게이트 |
| --- | --- | --- | --- |
| EPAS1, 상한 0.35 (현행) | 1.000 | 0.9637 | PASS 3/3 |
| EPAS1, **상한 없음** | 0.591 | **0.9260** | **PASS 3/3** |
| M1 HTS, 같은 n·활성 수 | 0.091 | **0.7213** | **1/3** |

**상한을 완전히 없애도 기억 베이스라인은 여전히 게이트를 3/3 통과한다**
(AUC 0.964 → 0.926). 타깃을 바꾸면 0.721 로 무너진다.

이유는 활성군의 성질이다.

| | 활성 최근접이웃 중위 | 유사체 ≥0.6 가진 활성 |
| --- | --- | --- |
| EPAS1 | **0.795** | **87%** |
| M1 HTS | 0.264 | 10% |

EPAS1 활성 60개는 **PT 계열 한 시리즈**다. 서로 닮았다. decoy 를 어떻게 고르든
"다른 활성과 닮았나" 가 그 시리즈를 집어낸다. **decoy 선택 규칙으로는 고칠 수
없다** — 활성군 자체가 벤치마크로 쓸 수 없는 모양이다.

M1 의 활성은 HTS 스크린에서 나와 화학적으로 다양하다. 그래서 기억이 안 통한다.

### 오늘 막힌 길

**EPAS1 에 쓸 실측 비활성이 없다.** PubChem BioAssay 에 EPAS1(+HLF 별칭)
어세이가 170개 있지만 전부 문헌 유래 소규모 IC50 어세이(시험 1~33개)이고
**비활성이 0개**다. 활성만 기록된 데이터라 "시험했는데 안 들었다" 가 없다.

11-03 에 "가장 흥미로운 데이터" 로 꼽으면서 "EPAS1 에 충분히 있는지만 확인하면
된다" 고 단서를 달았는데, 확인해 보니 없었다. → `scripts/probe_epas1_bioassay.py`

### 남은 선택지 — 측정으로 좁혀졌다

| | 길 | 판정 |
| --- | --- | --- |
| ~~B~~ | ~~상한을 없앤다~~ | **탈락.** 측정해 보니 AUC 0.926, 여전히 3/3 통과 |
| A | **타깃을 옮긴다** — 활성이 화학적으로 다양한 타깃으로 | **유효.** M1 에서 AUC 0.721, 1/3 |
| C | 고칠 수 없다고 보고하고 기억 베이스라인을 항상 병기한다 | 지금 하고 있는 것 |

**A 와 C 는 배타적이지 않다.** C 는 어느 벤치마크에서든 유지할 규율이고,
A 는 "도킹이 작동하는가" 를 물을 수 있는 벤치마크를 갖는 길이다.

A 의 대가: EPAS1 이 **벤치마크로는** 끊긴다. belzutifan 이라는 승인약 기준점을
잃는다 — 그게 애초에 EPAS1 을 고른 이유였다. 다만 **구조 선택 편향 측정
(간판 75%)은 EPAS1 에서 계속 유효하다.** 양 팔이 같은 라이브러리를 쓰므로
기억 지름길이 상쇄되기 때문이다. 두 질문이 다르다:

- "도킹이 작동하는가" → EPAS1 로는 답할 수 없다. 타깃을 옮겨야 한다
- "구조 선택이 숫자를 얼마나 바꾸는가" → EPAS1 로 답할 수 있다. A안 재실행

C 는 패배가 아니다. 우리가 파는 것은 "도킹이 작동한다" 가 아니라 "네 숫자 중
얼마가 인공물인가" 이고, 기억 베이스라인을 항상 병기하는 것이 바로 그 산출물이다.
