# Context of use

FDA·EMA *Guiding Principles of Good AI Practice in Drug Development*(2026-01-14)
4번 원칙이 요구하는 "명확한 context of use"다. 작성 2026-10-23.

## 이 파이프라인은 무엇을 하는가

ChEMBL에서 뽑은 화합물 라이브러리를 **단일 수용체 구조**에 대해 AutoDock Vina로
도킹하고, 스코어 순으로 순위를 매긴다. 그리고 그 순위가 **구조 선택에서 얼마나
나왔는지** 음성 대조군으로 측정한다.

## 무엇에 쓰라고 만든 것인가

가상 스크리닝 결과의 **신뢰도를 재는 데** 쓴다. 구체적으로:

- 같은 라이브러리·같은 설정에서 수용체 구조만 바꿨을 때 농축 지표가 얼마나 변하는지
- 그 차이가 통계적으로 유의한지 (짝지은 부트스트랩 2,000회)
- 승인약이 상위 1%에 회수되는지

## 무엇에 쓰면 안 되는가

- **결합 친화도 추정.** Vina 스코어는 순위용이다. −12.8 kcal/mol이 −12.8 kcal/mol의
  어피니티를 뜻하지 않는다.
- **전향적 후보 제안.** 전향적으로 검증된 바 없다. 실험 검증은 한 건도 없다.
- **구조 선택 편향이 측정되지 않은 결과의 사용.** 대조군 없는 결과는 ABSTAIN이며
  어떤 판단의 근거도 되지 않는다.
- **절대 성능의 타깃 간 비교.** 타깃마다 라이브러리 구성과 포켓 성질이 달라
  EF1%를 가로로 비교할 수 없다.

## 입력

| | 출처 | 비고 |
| --- | --- | --- |
| 수용체 구조 | RCSB PDB | 실험 구조만. AlphaFold 모델은 쓰지 않는다 |
| 활성 화합물 | ChEMBL, 10 µM 이하 | 상한 60개로 자른다 |
| decoy | ChEMBL 무작위, 물성 필터 통과 | 추정 비활성이지 확인된 비활성이 아니다 |
| 벤치마크 | 승인약·임상 화합물 | 양성 대조군 |

## 알려진 한계

1. **decoy는 추정 비활성이다.** 실제로 시험된 적 없다. EF 값은 decoy 집합에 따라
   달라진다.
2. **단일 구조·리지드 도킹.** 유도 적합을 모델링하지 못한다. EPAS1의 M252 측쇄
   뒤집힘이 실제로 belzutifan 회수를 막았다.
3. **입력 무결성 검사가 없다.** 교란 감사 탐지율 2/4. SMILES를 431개 섞어도
   지표가 변하지 않았다.
4. **MET 대조군 수용체에서 Mg²⁺를 제거했다.** Open Babel의 가스테이거 전하 부여가
   고립 단원자 이온에서 실패하기 때문이다. Mg 배위가 모델링되지 않으므로 절대
   해석에 영향을 준다. 양팔이 같은 전처리를 거치므로 비교 자체는 성립한다.
5. **유사도–농축 관계는 두 점뿐이다.** 0.400과 0.071. 그 사이와 바깥은 모른다.

## 판정을 읽는 법

| 판정 | 뜻 |
| --- | --- |
| PASS | 대조군 대비 유의하게 낫고 승인약을 회수했다. **그래도 실험 검증은 아니다** |
| ABSTAIN | 대조군이 없어 판단하지 않는다. 좋지도 나쁘지도 않다는 뜻이 아니라 모른다는 뜻 |
| FAIL | 대조군 대비 우위가 없거나 승인약을 못 찾았다 |
| INSUFFICIENT / INVALID | 라이브러리 구성 문제. 파이프라인 성능과 무관 |
